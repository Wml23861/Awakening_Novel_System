## 三、原创训练门槛

- [x] 至少 20 种不同技法各有独立题目、目标与情境限制。
- [x] 每题有不照搬名著人物、情节、场景和标志性桥段的原创故事片段或长篇结构训练材料。
- [x] 每题有技法作用自检与套路化检查。
- [x] 每题由未参与创作的新 Agent 独立初审，给出具体位置和结论。
- [x] 每题根据意见另存修改稿，保留原稿，不覆盖。
- [x] 每题有独立复验、最终评价、失败原因和改进记录。
- [x] 训练文本只保存在 `04_创作知识/创作能力训练/`；没有进入 `05_小说项目/11_正文/`。
- [x] 单次成功不升级稳定规则；未通过或证据不足项不记合格。

## 四、能力验证问题

- [x] 不同类型开篇。
