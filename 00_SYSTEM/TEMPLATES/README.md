# 标准模板索引

模板是空白工作工具，不代表相应工作已完成。使用时复制到目标目录并填写实际依据，不要直接覆盖母版。

| 文件 | 用途 |
|---|---|
| `SOURCE_VERSION.md` | 原著来源、版本、完整性和权利边界核验 |
| `CHAPTER_RESEARCH.md` | 单回/单章原著研究 |
| `STAGE_RESEARCH.md` | 每 10 回阶段总结与复核 |
| `CROSS_RESEARCH.md` | 四书交叉比较与融合边界 |
| `TECHNIQUE_EXTRACTION.md` | 创作心法提炼、训练与升级审查 |
| `TRAINING_RECORD.md` | 训练原稿、独立审稿、修改与复测 |
| `CHARACTER_ANALYSIS.md` | 人物档案、自主性与行动模拟 |
| `COMMERCIAL_RESEARCH.md` | 有来源、日期和样本边界的商业研究 |
| `ORIGINALITY_AUDIT.md` | 原创性与反模板审查 |
| `CONTINUITY_CHECK.md` | 人物、时间、地点、能力、物品和规则连续性 |
| `CHAPTER_DESIGN.md` | 后续阶段的章节设计 |
| `INDEPENDENT_REVIEW.md` | 独立责任编辑审稿与复验 |
| `READER_SIMULATION.md` | 明确标注的 AI 五类读者模拟 |
| `PLOT_FINGERPRINT.md` | 章节指纹、近 20 章对照与疲劳预警 |
| `RULE_CHANGE.md` | 规则变更、验证和版本留痕 |
