# 人物档案与自主性分析

> 用于原创人物时须经相应阶段授权；用于名著研究时，将事实标 F、解释标 I，不把推测当原著事实。

## 一、基本档案

- 姓名 / 身份：
- 外在特征：
- 成长经历 / 重要人生经历：
- 核心欲望 / 核心恐惧：
- 当前目标 / 长期目标：
- 利益诉求 / 情感需求：
- 价值观 / 性格特点 / 性格缺陷：
- 认知边界：
- 掌握的信息 / 不知道的信息 / 错误认知：
- 行动能力 / 拥有资源：
- 人物关系：
- 行为底线 / 底线突破条件：
- 可能发生的变化：
- 与主角的关系 / 独立剧情线：
- 人物最终可能走向（未确认则标候选）：

## 二、语言与行为辨识度

- 典型选择方式（不是固定口头禅）：
- 对话节奏、措辞与身份依据：
- 压力下、关系中、独处时的差异：
- 避免沦为刻板标签的反例：

## 三、人物自主性测试

- 如果主角不在场，此人物会做什么？
- 如果主角不出现，其人生是否继续？
- 是否有自己的利益和计划？
- 是否有独立于主角的情感关系？
- 是否可能反对主角或做出主角不理解的决定？
- 是否拥有自己的成长和变化？
- 是否会为选择承担代价？

## 四、行动模拟

- 事件：
- 此人物当时已知 / 未知信息：
- 目标、利益、资源、行动能力：
- 可选行动及理由：
- 对其他人物和局势的影响：
- 是否符合档案；若偏离，有何铺垫：

## 五、依据与版本

- 原著定位或原创设定文件：
- 事实 / 解释 / 待定设定分别列示：
- 连续性风险 / 待复核项：
- 更新日期 / 版本 / 审批状态：
