# 原创性规则

版本：0.1.0

## 1. 边界

- 不复制已有小说的具体表达、场景组合、人物关系设计和剧情序列。
- 不直接搬运四大名著人物进入原创小说，不用名著角色换皮充当原创人物。
- 公版文本可用于合法研究和必要短引，现代注释、校勘、翻译与整理成果须单独标明来源和权利边界。
- 技法规律可以学习，具体表达与可识别剧情不得直接套用；换名、换地图、换能力名称不构成原创。

## 2. 新剧情七问

1. 是否只是常见套路换名字？
2. 是否与最近章节重复？
3. 是否与已有作品具体剧情高度相似？
4. 是否有由本书人物自然产生的独特行为？
5. 冲突来源是否具体且非通用换皮？
6. 解决方式是否体现人物、规则与前期因果？
7. 是否推动本书特有主线并产生新故事价值？

## 3. 审查记录

原创性审查须记录审查对象、对比范围、具体位置、相似点与差异点、证据来源、风险等级、处理建议和人工结论。资料不足时明确“无法穷尽对比”，不得宣称绝对原创或绝无相似。

## 4. 工具限制

文本相似不等于抄袭，低相似也不证明原创。自动工具不能判断思想表达边界、场景必要性或文学价值，只提供需人工复核的线索。不得以规避检测器、同义改写或遮蔽来源为处理方式。

## 5. 处理原则

高风险设计回到人物目标、冲突因果和世界规则重新设计，而非仅替换措辞。保留审查和修改记录；引用或参考必须透明标注。
