# 独立审稿协议

版本：0.1.0

## 1. 独立性

正式章节由未参与该章创作的新 Agent 终审。审稿输入以文本、设定档案和必要上下文为准，不向审稿人暗示预期分数或必须保留的结论。创作意图不能抵消文本中的实际问题。

## 2. 审查顺序

1. 连续性检查。
2. 反模板与原创性检查。
3. 人物动机、信息边界、关系和行为检查。
4. 剧情因果、伏笔、反转与主线检查。
5. 商业阅读体验与模拟读者检查。
6. 独立责任编辑综合审稿。

相互独立的专项检查可并行；综合审稿须收到必要检查结果。普通日常章节不必无条件调用所有角色，重大冲突、反转、群像和卷末按风险增加检查。

## 3. 证据要求

每项评价给出章节、段落或短引文定位，说明问题表现、原因、阅读影响和修改方向。不得只写“不好”“缺乏感染力”，也不得把个人偏好冒充客观错误。无法核实原著或设定时标待复核。

## 4. 评分（辅助）

| 维度 | 分值 |
|---|---:|
| 故事吸引力 | 15 |
| 人物真实性 | 15 |
| 剧情合理性 | 15 |
| 情绪与爽感 | 15 |
| 阅读节奏 | 10 |
| 语言自然度 | 10 |
| 原创性与辨识度 | 10 |
| 连续性与伏笔 | 10 |

90 分以上进入最终核验；85—89 检查关键问题；80—84 修改后重审；80 以下重新设计问题部分。分数不替代判断。

## 5. 一票否决

重大逻辑漏洞、人物严重崩坏、核心设定冲突、未经铺垫的重大反转、严重抄袭、破坏全书主线、严重连续性错误不得被平均分抵消。抄袭判断需证据，不能仅凭相似度工具输出。

## 6. 修改与验收

- 区分“必须修改”与“可选建议”，避免为统一风格抹平人物语言。
- 保留原稿、审稿报告、修改稿和复验结论。
- 重大问题必须退回作者；复验需确认问题实际消除且未引入新问题。
- 模拟读者评价必须标明“AI 模拟”，与真实读者数据分开保存。
- 未经实际审稿，不得在状态文件写“通过”。
