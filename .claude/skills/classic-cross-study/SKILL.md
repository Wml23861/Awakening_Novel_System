# 四大名著交叉研究

1. 核对当前为 PHASE 3 且四书逐回研究与独立验收确已完成；不满足则停止，不能先写综合结论。
2. 读取四书综合研究和相关已复核分回报告，记录版本与证据范围。
3. 使用 `literature-scholar` Agent 和 `交叉研究.md` 模板，分别比较人物、情节、群像、冲突、世界观、叙事、伏笔、情绪、语言和长篇结构。
4. 分别回答 A—H：独有优势、共同规律、差异、可融合、不可融合、觉醒题材适用、商业不适配及副作用。
5. 原著事实、研究解释、迁移建议分层；列出反例、替代解释、样本边界与待训练假设。
6. 由另一独立角色复核证据和逻辑，保存总报告并更新真实状态。

不得把四书技法简单拼成清单，不得将迁移建议冒充原作者意图。
