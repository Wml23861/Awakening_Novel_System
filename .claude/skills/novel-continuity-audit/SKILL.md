# 连续性审查

1. 明确检查章节和设定基线版本，读取人物档案、时间线、地点、能力物品、世界规则、伏笔悬念及近期正文。
2. 缺资料先列出并限制结论，不凭记忆补齐。使用 `continuity-keeper` Agent 和 `CONTINUITY_CHECK.md`。
3. 逐项核对人物名称/状态/当时认知、时间移动、地点、能力限制与代价、物品归属、规则、伏笔和关系变化。
4. 每个冲突给出基线、当前位置、表现、严重程度和修改建议；自动工具警告必须人工复核。
5. 区分文本矛盾、可合理解释的变化和待用户确认的设定变更，不擅自修改正文或核心设定。
6. 保存报告，修改后复验并更新相应状态档案。
