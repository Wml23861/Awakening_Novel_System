# 原创性与反模板审查

1. 确认审查对象、版本、对比范围和可用工具，读取原创性规则、反模板规则和近 20 章剧情指纹。
2. 使用 `originality-auditor` Agent 和 `ORIGINALITY_AUDIT.md`，逐项回答新剧情七问。
3. 记录具体位置、对比依据、相似与差异、新故事价值和风险；明确无法穷尽的对比范围。
4. 检查冲突、爽点、结尾、人物行为、信息揭示、对话和句式重复。主题呼应可保留，但须说明新变化。
5. 自动工具输出只作线索；人工结论不得把相似度直接等同抄袭，也不得承诺绝对原创。
6. 高风险问题回到人物、因果和规则重新设计，不仅替换词语。保存审查与复验结果。
