# 创作能力训练

1. 确认 PHASE 5 已获授权，读取训练目录、相关心法和 `TRAINING_RECORD.md`。
2. 使用 `story-coach` Agent 明确级别、题号、目标、限制和验收点；训练文本只保存到对应 L1—L4 目录。
3. 保留原始作品，不覆盖。完成后交给未参与创作的 `independent-reviewer`，要求具体位置、问题依据和是否达到题目要求。
4. 根据必须修改项另存修改稿并复验；保留失败原因、改进记录和最终评价。完成题目不等于合格。
5. 心法验证须记录支持、不支持或证据不足，以及适用条件和副作用。单次成功不能升级稳定规则。

禁止把训练作品拼入正式正文，禁止由创作者自审宣布通过，禁止提前展开正式小说设定。
