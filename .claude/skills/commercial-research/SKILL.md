# 商业小说研究

1. 确认 PHASE 4 已获授权，明确研究主题和样本问题，读取研究协议与现有商业资料。
2. 使用 `commercial-editor` Agent。优先官方公开规则、作者帮助、合法作品信息、真实评论和用户数据；必要时使用网页工具核验。
3. 按 `商业研究报告.md` 记录 URL/文件、发布日期、获取/核验日期、样本选择、访问和权利限制。
4. 区分可核验事实、编辑解释、迁移建议与传闻。不得由单个爆款推出普遍规律，不得编造平台算法。
5. 分析有效原因、适用条件、失败情形、反例和对人物逻辑的副作用；提出可验证实验而非绝对公式。
6. 保存到对应主题目录，更新商业创作方法论时保留证据索引和未验证内容。

AI 读者模拟不能充当真实评论或市场数据，研究结论不得自动变成固定写作模板。
