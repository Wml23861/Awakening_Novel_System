# 标准模板索引

模板是空白工作工具，不代表相应工作已完成。使用时复制到目标目录并填写实际依据，不要直接覆盖母版。

| 文件 | 用途 |
|---|---|
| `来源版本.md` | 原著来源、版本、完整性和权利边界核验 |
| `章节研究.md` | 单回/单章原著研究 |
| `阶段研究.md` | 每 10 回阶段总结与复核 |
| `交叉研究.md` | 四书交叉比较与融合边界 |
| `技法提炼.md` | 创作心法提炼、训练与升级审查 |
| `训练记录.md` | 训练原稿、独立审稿、修改与复测 |
| `人物分析.md` | 人物档案、自主性与行动模拟 |
| `商业研究.md` | 有来源、日期和样本边界的商业研究 |
| `原创性审查.md` | 原创性与反模板审查 |
| `连续性检查.md` | 人物、时间、地点、能力、物品和规则连续性 |
| `章节设计.md` | 后续阶段的章节设计 |
| `独立审稿.md` | 独立责任编辑审稿与复验 |
| `读者模拟.md` | 明确标注的 AI 五类读者模拟 |
| `剧情指纹.md` | 章节指纹、近 20 章对照与疲劳预警 |
| `规则变更.md` | 规则变更、验证和版本留痕 |
