## 一、启动前提与顺序

只有同时满足以下条件，才可执行首个逐回任务：

1. 用户明确确认进入 PHASE 2。
2. 使用用户认可的殆知阁研究底本，实际研究文本与对应文件、SHA-256 和版本说明绑定；不混用其他版本，不用模型记忆补写原文或研究结论。
3. 研究者读取创作宪法、研究协议、项目状态、对应版本说明和章节模板。
4. 对底本中已定位的电子文本异常保留阅读标记；这些异常不再作为资料准入门禁。

## 二、统一研究标准

每回使用 `00_系统/模板/章节研究.md`，覆盖：

- 开场吸引力及其具体位置。
- 事件因果、冲突来源、双方诉求和解决方式。
- 人物动机、利益、信息边界、魅力与缺陷。
- 关系变化、配角与对立者的独立目标和群像自主性。
- 伏笔、悬念、反转及其前期依据和后续兑现状态。
- 对话、动作、物件、环境与身体细节的实际作用。
- 紧张、幽默、快意、悲悯等具体情绪及其积累变化。
- 叙事视角、信息控制、详略与节奏。
- 人性、社会、命运和思想层次，区分文本事实与现代解释。
- 现代商业迁移机制、原创替换要求、同质化风险和训练验证需求。

这些维度不是固定情节公式。某回没有反转、明显开场钩子或思想阐述时，应如实分析实际写法，不强行凑项。AI 读者体验不是实际读者数据，迁移建议未经 PHASE 5 训练与独立评价不得称为稳定心法。

## 三、单回与十回工作流

### 单回任务

1. **阅读与定位**：实际读取该回完整研究文本，记录底本、文件和起止位置；发现缺字或异文先登记 Q，不猜补。
2. **初步研究**：按模板形成报告，关键事实标 F，文学解释标 I，现代迁移标 T，未核信息标 Q；完成后只能标“已完成初步研究”。
3. **独立复核**：由未参与该回研究的新会话 / 独立 Agent 检查阅读范围、引文定位、事实与解释边界、过度概括及遗漏；研究者不得替自己终审。
4. **退回或通过**：重大问题退回补充并保留意见；通过后才能标“已复核”。
5. **更新台账**：同步章节目录、研究进度和待复核项，不伪补报告路径或复核日期。

### 每十回任务

- 汇总该组实际报告及状态；未覆盖范围明示。
- 按 `00_系统/模板/阶段研究.md` 检查跨回因果、人物与关系、群像、情绪、节奏、伏笔、语言、思想及迁移假设。
- 阶段结论须有多回依据，并另列仅属单回的现象。
- 独立复核通过后才计该十回阶段总结完成；每十回总结不替代单回报告。

### 全书与跨书任务

- 一部书全部回目已复核后，才开展该书综合研究，并将实际纳入的章节标为“已纳入综合研究”。
- 综合研究仍须指出文本限制、矛盾和未决问题，不能用既定印象覆盖逐回证据。
- 四书综合研究全部完成后，依据用户 2026-10-30 的连续推进授权进入 PHASE 3 交叉比较；此前不预写交叉结论。
