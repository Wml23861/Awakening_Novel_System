# 长篇剧情架构手册（阶段性样本版）

- 文档性质：阶段性结构方法假设与训练工作纸，不是正式小说总纲或分卷大纲。
- 样本范围：SG-01、SG-02、SH-01、XY-01、HL-01，即《三国演义》第1—20回及其余三书第1—10回。
- 证据边界：只使用上述已复核阶段研究，不读取、不借用范围外后文；F、I、T、Q分别表示原著事实、研究解释、迁移建议和待核事项。
- 阶段边界：PHASE 2未完成，PHASE 3正式交叉研究与PHASE 5专项训练未完成；本稿不宣称任何正式阶段验收通过。
- 创作边界：不确定书名、主角、世界观、觉醒体系或正式剧情；十章示例仅供原创训练。
- 效果边界：未进行真实读者、平台或商业研究，所有吸引力、疲劳和节奏判断均为待验证解释。

## 一、主线、阶段、单元、多线与卷

### 1. 主线与阶段目标

主线是贯穿多个阶段的核心变化问题，不是主角遭遇事件的目录。一条可工作的主线至少回答：

- 哪个或哪些人物持续追求什么，为何不能一次完成？
- 哪些人物会因自身利益持续改变其条件？
- 每个阶段改变主线的哪项状态，如何证明不是只增加经历？

**T：**不要只写“查明世界真相”“成为最强”。须把真相与行动、能力与责任、目标与代价连接起来。
阶段目标是某一时期可核验的具体结果，如取得许可、完成救援、重建信用或达成有限协议。阶段结束时应能回答：

1. 哪个旧问题已解决，解决到哪一层？
2. 哪项人物、关系、资源、信息或制度状态不可逆地改变？
3. 哪些代价已结算，哪些成为明确责任？
4. 即使暂不进入下一阶段，本阶段是否仍有独立故事价值？

“打了很多场”“认识了很多人”“知道更多秘密”本身不是充分的阶段结果。

### 2. 单元与多线

单元围绕一个相对完整的行动问题形成，可长可短、可跨线，也可嵌入另一单元。它至少应有局部目标及发起者、多方反应、改变条件的选择、可辨认结果与余波，以及对人物或主线的独立价值。
单元不必以战斗为高潮，不必完全封闭，也不必换地点。谈判、求助、学习、照护、调查、等待和修复均可构成单元。
多线是多个行动中心各自推进，不是同一主线被随机切段。每条重要支线应登记：

- 独立目标、信息边界、资源、阻力与时间表；
- 不依赖主线时仍在发生的行动；
- 与主线交换人员、信息、资源、风险或后果的接口；
- 合流、分离或暂歇后保留的状态。

**I：**SG-02的徐州、朝廷、孙策等线通过后方、诏命、投依、书信与后勤相互作用；SH-01的视线交接则由教学、寻找、结义和押送等人物行为完成。

### 3. 卷级结构

卷是具有独立目标、冲突组合、关系变化、阶段高潮、结果和新方向的结构单位，不是固定章数容器。一卷至少应完成一种实质变化：

- 一个局部事业成功或失败并留下后果；
- 一段关系经过行动检验后重组；
- 一项认知经证据与代价检验后落实；
- 一种秩序被建立、修改或证明有限；
- 一个长期问题获得阶段答案，同时显露更深一层。

禁止“每卷换地图—遇新敌—获新能力—打更强对手—清零再来”。地点和敌人可以改变，但必须服务本书独有的目标、因果和人物关系。

### 《西游记》前十回的特别边界

**Q：**XY-01只覆盖求道与冲突、条件性招募、任务建立及其他线索。第8回末尚未寻定取经人，悟空未脱山，团队未同行，传经任务未开始执行。
因此，前十回**不能证明完整单元旅途规律**，不能据此总结“每到一个地点遇怪—解决—继续”，也不能宣称已经研究完整的取经旅途周期。
本稿只迁移其中可定位的跨回因果、条件协商、信息、代价和完成义分账；旅途型结构仍须全书研究及独立训练验证。

## 三、从主线到卷、阶段和单元

### 1. 先确定持续故事发动机

- 谁长期想要什么，谁有理由不让其轻易实现？
- 哪种有限资源或不可兼得价值会反复产生新选择？
- 世界既有规则如何让同一问题在不同关系中出现新形态？
- 为什么这些事件只能由本书这些人物这样解决？

若把角色换成任意“天选者”仍完全成立，主线独特性不足。
把主线拆成状态变化，而非敌人列表，例如“从个人应付到有限合作”“从知道受害结果到证明责任链”“从依赖个人信用到形成可核验程序”。每段只写当前准备完成的变化，不预写未经确认的全书答案。

### 2. 配置具体冲突

- 目标冲突：各方想要的东西不同；
- 手段冲突：目标相近但伦理与风险排序不同；
- 信息冲突：各方依据不同的真实碎片行动；
- 资源冲突：时间、权限、信用、身体或物资不足；
- 关系冲突：情义、家庭、旧诺与新责任不可兼得；
- 执行冲突：正确方案缺少批准、能力或协作；
- 后果冲突：解决一方问题把成本转给另一方。

不必每项都用。选择越少越应深入，而不是为“丰富”强添敌人。
每个关键节点分别列出各方“已知／未知—目标—利益—风险—资源—权限—可选行动—最可能行动”，再由碰撞推导局势。若预定结果要求某人放弃合理核验、泄露秘密或忘记能力，应修改结果或前置条件。
单元边界由目标或条件变化决定，不由固定章数决定。可压缩过渡、详写不可逆选择；正文不得按内部表格顺序机械展开。

## 四、五本长期故事账

账本用于防止遗忘和伪造因果，不是要求正文展示表格。每次只更新真实发生的变化，保留历史版本。

### 1. 阶段故事账

| 字段 | 记录要求 |
| --- | --- |
| 范围与旧问题 | 实际起止；上一阶段留下且本阶段确实处理的问题 |
| 阶段目标 | 发起者、期限、可观察完成标准 |
| 核心阻力 | 人物行动与既有条件，不写抽象困难 |
| 关键选择 | 谁决定、依据什么、放弃什么 |
| 结果分层 | 个人／团队／旁观者，局部／整体，暂时／持续 |
| 独立价值 | 即使停下，本阶段完成了什么 |
| 新问题与责任 | 由哪些旧行动产生；承诺、伤害、债务及承担者 |

审查重点：阶段结果是否只换地点和对手；主线状态是否实际改变。

### 2. 人物行动账

| 字段 | 记录要求 |
| --- | --- |
| 人物与目标 | 目标可变化，但须有事由 |
| 已知与误信 | 信息来源及获知时点 |
| 欲望与利益 | 公开及私人理由均须有行动依据 |
| 资源与权限 | 能做什么、能决定什么分别登记 |
| 风险边界 | 家庭、名分、安全、生计、伦理等限制 |
| 实际行动 | 不将建议、承诺、计划写成已完成 |
| 对他人影响 | 帮助、限制、伤害、暴露或授权 |
| 下一步 | 即使离开主线仍保留的合理行动 |

审查重点：配角是否只在主角需要时行动；人物是否因预定胜负而降智。

### 3. 信息账

| 字段 | 记录要求 |
| --- | --- |
| 编号与内容 | 区分事实、指控、转述、预示和推测 |
| 来源与载体 | 亲历、文书、物证、传闻、专业判断等 |
| 知情者及时间 | 读者与人物分开登记 |
| 屏蔽条件 | 为何无法获知、核验或公开 |
| 证据与反证 | 支持范围、矛盾和仍未知部分 |
| 揭示场景 | 谁先知道、如何知道、是否可公平回查 |
| 行动后果 | 知道后实际改变何种选择 |
| 状态 | 未知、部分证实、已证实、误读、已公开、待复核 |

审查重点：揭示是否只增加秘密而没有行动后果；人物语言是否被误升为客观事实。

### 4. 代价账

| 字段 | 记录要求 |
| --- | --- |
| 对应选择 | 哪项行动或拒绝产生代价 |
| 即时与延后成本 | 时间、身体、资源、机会、关系、安全及回返依据 |
| 支付者与受益者 | 主角、协作者、对立者、旁观者分别记录 |
| 可逆性 | 可修复、可补偿、不可逆，不能混写 |
| 偿还与余波 | 是否已道歉、补偿、修复或仍被回避 |
| 防重置说明 | 后续如何保留身体、信用、关系或制度痕迹 |

审查重点：是否让无声者长期代付成长成本；是否所有成功都被强行附加同等悲剧。

### 5. 伏笔悬念账

| 字段 | 记录要求 |
| --- | --- |
| 编号与类型 | 伏笔、悬念、承诺、计划、预示、未决责任 |
| 设置位置 | 首次出现的具体事件 |
| 已知功能 | 行动条件、关系依据、证据或主题对照 |
| 当前状态 | 未触发、部分兑现、已兑现、转化、失效待审 |
| 兑现条件 | 哪个行动或证据可使其结算 |
| 最迟复核点 | 到时判断兑现、转化或承认搁置 |
| 兑现后作用 | 必须改变行动、关系、理解或风险 |
| 剩余问题 | 局部兑现后仍未解决的具体事项 |

审查重点：不是所有物件都叫伏笔；计划不等于结果；长期未兑现不得以“以后有大用”无限延期。

## 五、旧问题解决后，如何自然留下新问题

### 1. 区分解决对象与使用手段

先写清旧问题解决了什么，再审手段引入了什么。取得许可解决进入权，不自动解决分配；救出某人解决眼前危险，不自动解决庇护与身份；公开证据解决真伪，不自动解决安全与执行。
使用六类后果接口：

1. **身份：**新职位、罪名、名分或代表责任。
2. **资源：**消耗、借用、质押或重新分配留下余量与债务。
3. **关系：**合作、救援、欺骗和惩罚改变信任与退出成本。
4. **信息：**真相产生公开、保密、核验或执行难题。
5. **制度：**临时措施成为先例，受益者与受损者要求不同处理。
6. **群体：**中心人物脱困，协作者或旁观者仍承担损失。

### 2. 结果分账与因果测试

每次收束分别核对目标完成度、症状与根因、个人与群体、当前与长期安全、正当目标与执行、情感和解与物质补偿。只有确实完成的项目才能标完成；剩余项须具体，不用“更大阴谋”替代。
并非每次解决都必须制造新问题。可以留下安定、喜悦、日常和不可逆的正向成果；下一目标也可由人物主动选择，而非世界不断惩罚上一目标。
新问题须通过以下测试：

- 没有上一选择，它仍会以完全相同方式发生吗？若是，是否真属本阶段后果？
- 它是否只提高敌人等级，或要求旧人物反常行动？
- 能否在现有规则、关系和资源中找到生成路径？

无法回答时，应保留平稳收束或重新设计，不硬造危机。

## 六、多线与卷级组织

| 组织方式 | 工作机制 | 主要风险 |
| --- | --- | --- |
| 连续目标型 | 同一目标跨单元，各单元改变信息、资源、关系或权限 | 同一障碍重复尝试而无新条件 |
| 人物交接型 | 通过教学、委托、合作、竞争或责任转移接续重心 | 前人物目标被遗忘，交接只介绍角色 |
| 多中心交汇型 | 各线独立运行，通过资源、信息、人员与后果交汇 | 转场无接口、名单膨胀、各线同功能 |
| 日常累积型 | 小事件改变关系、信用和共同规则，阶段高潮兑现累积 | 无后果插曲冒充生活感，反复靠误会 |
| 证据重释型 | 新证据改变旧事件的责任解释和人物选择 | 反复推翻却无确定事实与新行动 |

新卷须有清楚的独立目标、实质状态变化和非重复的核心冲突，不能只换地名、敌人名和能力数值。主导目标、关系结构、冲突来源、行动权限、信息状态、情绪基调和解决方式只作诊断维度；是否改变及改变几项由实际叙事需要决定，不设数量门槛。

## 七、十章训练用结构示例

> 仅用于练习五本账和阶段收束，不是正式小说大纲，不对应任何已确定设定。角色以职能代称，十章长度不是推荐公式。

### 1. 主线、阶段价值与行动者

**训练主线问题：**一个依靠个人威望处理危机的共同体，能否在不抹平成员差异的情况下建立可质疑、可追责的合作方式？
**阶段目标：**在共用仓库停用审查前，查清一批公共物资的去向，并决定是否、如何重新开放仓库。
**独立价值：**即使不再扩展，本阶段仍完成一次责任调查、公开处置和共同授权实验。
**主要行动者：**

- 记录员：想证明前任没有私吞，也想保住职位。
- 仓管员：曾用紧急权力开仓，认为结果比程序重要。
- 运输员：希望先偿还欠薪，掌握实际运输路线。
- 住户代表：需要物资，也反对紧急权力长期不受监督。
- 审查员：倾向永久停用以避免再次担责，并非单纯反派。

### 2. 十章事件与账目联动

| 章次 | 核心事件与局部价值 | 信息、行动和代价变化 | 收束或自然新问题 |
| --- | --- | --- | --- |
| 1 | 盘点发现账面齐全，住户却未收到；记录员拒绝先写损耗结案 | 仓管员承认曾口头放行但无记录；记录员拒签会失去审查员支持 | 要重建实际流向，而非只找钥匙 |
| 2 | 三人沿运输路线核对；运输员要求先解决欠薪才交票根 | 票根只证明部分物资到过临时点；欠薪进入代价账 | 查账须同时处理劳动成本 |
| 3 | 临时点签收证明部分物资确曾救人，仓管员获得实际支持 | 记录员理解程序缺失不等于没有正当用途；剩余流向未知 | 正当结果能否豁免说明义务 |
| 4 | 运输员自行把一车剩余物资送另一急需点 | 解决当地短缺，却使审查前无法归库；仓管员要求隐瞒 | 救助手段伤害共同信用 |
| 5 | 公开核对会上，记录员拒绝推责，也拒绝用救人免除记录义务 | 她公开自己曾补写便签并承担职位风险；住户愿提供私人收据 | 真相推进来自承担而非自供 |
| 6 | 收据与旧账拼合，重复登记来自两套用途不同的记录，并非统一阴谋 | 审查员认可事实链但仍否定制度；记录员理解执行断点 | 查清后仍须决定是否重开 |
| 7 | 讨论重开方案：双人授权能追责，却会延迟紧急救援 | 仓管员反对繁琐，住户担心例外，运输员要求纳入欠薪和值班 | 新制度自身成本显现 |
| 8 | 演练暴露双人授权在夜间联系人缺席时失效 | 不新增万能权限；改用限定品类、额度的紧急清单并保留复核 | 局部可行但适用范围有限 |
| 9 | 审查决定限期重开，撤回前任私吞指控，贡献与违规分别记录 | 记录员保住职位却失去单独管账权；运输员只获分期欠薪 | 目标完成，旧信任未立刻恢复 |
| 10 | 首次按新规分配完成，另一共同体请求照搬制度 | 记录员拒绝提供标准答案，先说明本地条件和失败边界 | 新问题是跨共同体协商而非强敌 |

### 3. 单元、多线与收束抽查

- 单元一（1—3）：核对流向，区分无私吞、程序缺失与实际救助。
- 单元二（4—6）：处理独立运输行动与公开责任，让真相和承担共同推进。
- 单元三（7—9）：设计并测试重开方案，使制度选择接受成本检验。
- 第10章为兑现后静段与新方向，不强行再制造事故。

记录员、仓管员、运输员和审查员均有独立目标，通过票根、权限、劳动成本和风险相互改变，而非轮流给记录员送线索。
五本账抽查：物资流向查清、仓库限期重开是阶段结果；运输员第4章行动持续影响后文；票根、签收、便签和收据各只证明有限事实；记录员失去单独管账权、欠薪仅分期，未完全补偿；前任指控已兑现，欠薪、紧急清单适用范围和跨共同体请求分别保留，不混成一个大谜团。

## 八、长篇疲劳信号

以下信号只提示人工复核，不能凭出现一次自动判错：

- **冲突：**连续单元都由挑衅、误会或同一秘密引发；对手只增加数量等级；讨论不改变资源或权限。
- **结果：**胜利反复被立刻撤销；失败总由意外救援；阶段只得到下一地图；所有成果都附加同类悲剧。
- **人物：**配角只送资源、受辱、解释或惊叹；主角总以同法证明正确；重大事件不留关系和风险判断痕迹。
- **信息：**揭示只换身份标签；同一问题反复“还不能说”却无人核验；伏笔只增不兑；名录没有因果功能。
- **能力与代价：**新能力回答所有问题；限制随胜负消失；代价只宣告不留痕；成长反复是受难—顿悟—升级。
- **节奏：**章末全是无信息危险句；静段只重复说理；单元长度和转折位置雷同；切线只为拖延答案。

## 九、补救方法与边界

### 1. 可优先采用的补救

- 合并重复单元，保留最能体现人物差异和因果变化的一次。
- 提前兑现部分旧问题，把篇幅转给兑现后的行动难题。
- 保留稳定成果，让新冲突来自新责任，而非撤销进展。
- 用谈判、核验、协作、退出、等待或公开承担替代重复对抗。
- 从配角目标恢复其行动，不增加无功能新角色。
- 压缩无接口的名录与转场，背景信息不冒充剧情。
- 重排证据与选择的顺序，而非继续加秘密。
- 用已发生后果改变后续选择，不靠人物口头复述。

### 2. 不可越过的边界

不得为救场临时新增能力、血统、权限或万能道具；不得未记录、未确认便改变底层规则；不得让对手降智或集中自供；不得删除已发生代价。
不得用更高敌级、更多地图掩盖主线停滞，不得无限延期已承诺兑现，也不得以AI自评、模拟读者或机器报告宣称疲劳已经解决。
若主线只能依赖重复敌人推进，局部加场无法根治，应回到长期目标、不可兼得价值和既有规则重新设计。
若核心设定已被用户确认，不得擅改；重大重构须列备选、代价、连续性风险和待确认事项。训练稿另存版本比较；正式稿保留原稿、问题依据、修改版本和独立复验。

## 十、阶段与卷级审查清单

### 主线、人物与独立价值

- 本阶段改变了主线的哪项可观察状态？删除它，后续是否真会不同？
- 本阶段单独阅读是否有目标、选择、结果和余味？
- 冲突来源与解决方式是否体现本书人物，而非通用换皮？
- 每条线是否有自己的目标、时间表和改变主线的具体接口？
- 建议、批准、执行和承担是否分清？离场人物是否仍保留目标与后果？

### 信息、代价与伏笔

- 读者和人物各自知道什么，来源是否可追踪？揭示是否改变行动？
- 哪些线索已兑现，哪些只是计划、预示或未决责任？是否到最迟复核点？
- 谁获益、谁支付、谁未获补偿？哪些成果可以稳定保留？
- 新问题是否由旧选择的身份、资源、关系、信息、制度或群体接口产生？

### 反模板与连续性

- 是否换地图、敌人、能力名却重复同一过程？
- 相似场景是否新增信息、关系、成本或风险？
- 是否出现固定章数觉醒、反转、高潮或断章？
- 新增规则是否必要、是否影响旧事件、是否经相应确认？

## 十一、训练验证与样本版结论

**T：**优先训练“一个旧问题的完成如何改变下一阶段行动条件”，而不是训练固定卷首、卷中和卷末事件。
五本账在阶段／卷级共同核对：故事账说明完成什么，人物行动账说明谁使之发生，信息账说明谁知道什么，代价账说明谁承担，伏笔悬念账说明什么仍须兑现。逐场只更新实际受影响的账，不要求每场填满五表。

最小核心记录只保留：当前问题、行动者目标与信息、实际行动与结果、代价及未决项。相同字段引用人物行动卡、情绪设计卡等现有记录，不重复建账；重大转折、高代价选择、核心反转或重复风险高的节点，再启用完整专项表和审查记录。
卷级独立价值与长期连续性并不冲突：前者保证本卷真实完成某件事，后者保证完成后的状态不被重置。
**Q：**当前样本不足以确定最佳卷长、单元频率、多线比例、旅途周期或商业节奏；《西游记》前十回尤其不能证明完整单元旅途规律。
后续训练须保留结构原稿、受影响的账本记录、独立评价、修改稿和复测记录。结构完整、表格齐全和AI自评均不等于小说好看，也不等于正式训练合格。
