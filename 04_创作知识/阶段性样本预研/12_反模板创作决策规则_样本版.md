# 反模板创作决策规则（阶段性样本版）

- 版本：0.1.0-sample
- 日期：2026-11-02
- 性质：P2S-E0阶段性预研成果；供后续获准的创作设计与训练使用，不是稳定心法，不是正式小说正文。
- 核心任务：面对具体创作问题，先决定“什么问题值得解决、谁会怎样解决、要付什么代价”，再决定是否采用某种技法。
- 反模板目标：减少机械、重复、换皮和缺乏人物根据的表达；不追求规避AI检测，不虚构平台偏好或算法规律。

### 2. 不得越过的边界

- 不以本稿确定书名、主角、世界观、觉醒体系或正式剧情。
- 不把“局部胜利另有代价”反用成“每次胜利必须失败”，也不把“信息差”变成每章必有的反转。
- 不规定每章危机、觉醒、爽点、反转或断章的次数，不用“方案必须彼此完全不同”制造机械多样化指标。
- 不用自动相似度、AI评分或模拟读者代替人工文学判断；低相似不证明原创，文本相似也不直接等于抄袭。
- 后续新增研究样本可能提供反例；本稿须随之复核，不能因其已成文而免于修改。

## 二、总决策顺序：先问故事，再选技法

各设计按同一问题顺序判断，但记录分级：常规过场、连续性修补和已有唯一合理行动的场景使用简版问题单；重大转折、高代价选择、核心反转或重复风险高的场景执行完整九步留痕。前项未明，不用后项的技巧补丁掩盖。

1. **剧情要解决的问题：**当前谁想改变什么，什么具体条件阻止他，本段结束后哪一项状态必须不同。
2. **人物真实目的：**分别写公开目标、私人利益、不愿承受的损失；不把阵营目标当成每个人的目标。
3. **信息与权限：**列人物和读者各自知道、误信、不知道什么，信息从何而来，谁有能力和权力执行。
4. **当前情绪需要：**承接上一段未消化的情绪，判断此处需要积累、释放、停顿、转调还是保留不适。
5. **按风险比较方案：**常规场景记录一个可行方案及必要替代项；重大节点至少比较三种方案，方案须改变行动或因果，不是同一过程换三种说法，其中至少一种明确不采用已想到的熟套技法。三案先共同通过人物、信息、权限和因果硬约束，再比较取舍。
6. **后续影响与代价：**按实际涉及范围核个人、关系、群体、规则账，无涉项不强填；区分已解决、暂缓、恶化与尚未兑现。
7. **选择理由：**说明所选方案为何最符合人物、因果、情绪与主线，而不是只因其“更新奇”或“更爽”。
8. **反模板与原创性复核：**检查近章重复、七问、对话、句式和可识别桥段组合；重大风险回到设计层。
9. **训练验证：**保存原方案、原稿、独立意见、修改稿与复测；未实际完成，不标“有效”或“通过”。

三个硬约束贯穿全程：不得为预定结果让人物降智；不得临时增加无成本能力或改变底层规则；不得只换名称来掩盖来源。

## 三、可执行决策树

```text
开始：这是获准的训练，还是已获准的正式创作？
├─ 阶段未授权／核心资料冲突 → 停止扩写，报告缺项；不得编造补齐。
└─ 已授权
   → 1. 用一句话写“谁因何受阻，本段要改变什么”。
      ├─ 只有“要爽／要反转／要收尾” → 重找人物问题，不进入技法选择。
      └─ 问题具体
         → 2. 每个相关人物分别写目标、底线、资源、可能行动。
            ├─ 所有人都按主角需要行动 → 补独立利益与自主行动模拟。
            └─ 行动有各自根据
               → 3. 建信息表：知道／误信／未知／来源／知道时间／执行权限。
                  ├─ 秘密只靠作者隐瞒或角色不核验常识 → 重做信息链。
                  └─ 信息链可回查
                     → 4. 写入场情绪、目标情绪、不得出现的虚假情绪。
                        → 5. 按风险选记录层级。
                           ├─ 常规场景 → 记录一个可行方案及必要替代项。
                           └─ 重大转折／高代价／核心反转／高重复风险
                              → 列至少三种因果方案，含“不用熟套技法”的方案；三案均先通过人物、信息、权限和因果硬约束。
                                 ├─ 只有措辞、视角或顺序不同 → 不算三个方案，继续设计。
                                 └─ 行动与结果确有差异
                        → 6. 所有场景均比较即时效果、长期代价、受损者、未决项和主线价值。
                           → 7. 选一项并写不选其他项的理由；常规场景可简述。
                              → 8. 七问＋近20章指纹＋对话／句式审查。
                                 ├─ 换皮、人物崩坏、信息作弊、规则冲突 → 回到1或2重做。
                                 ├─ 仅局部语言冗余且因果成立 → 定点修改，保留依据。
                                 └─ 无可定位阻塞问题 → 形成训练稿／待独立审稿稿。
                                    → 9. 独立评价、修改、复测并保存记录。
                                       ├─ 未训练／未复测 → 只能保留T候选。
                                       └─ 单次表现良好 → 仍不升级为普遍公式。
```

若正式写作已批准，决策树不能替代写作协议中的连续性、人物、剧情、商业体验检查及独立终审。

## 四、三张前置工作表

### 1. 剧情问题单

| 项目 | 必答内容 | 不合格示例 |
|---|---|---|
| 当前问题 | 具体人物、目标、障碍、时限；只写本场能处理的范围 | “让主角更强大” |
| 状态变化 | 行动后资源、关系、信息、身份或责任中哪项改变 | “气氛更紧张” |
| 主线价值 | 对本书特有矛盾增加了什么新可能 | “又来一个更强敌人” |
| 可不解决项 | 哪些伤害或悬念允许留待后文，何时复核 | 为显得复杂而全部悬置 |

### 2. 人物目的与信息表

| 人物 | 公开目标／私人目的 | 不愿付出的代价 | 已知／误信／未知及来源 | 能力与权限 | 最可能自主行动 |
|---|---|---|---|---|---|
| 行动中心 |  |  |  |  |  |
| 合作者 |  |  |  |  |  |
| 对立者 |  |  |  |  |  |
| 受影响者 |  |  |  |  |  |

读者信息另列一行，不默认读者全知，也不把读者后见知识倒灌给人物。
“误信”须有证据、转述、立场或环境依据；“不知道”须有屏蔽条件。
专业判断、正式批准、实际执行和后果承担可属于不同人物，不能合并成一个人全知全能。

### 3. 情绪任务单

- 入场残留：上一事件尚未消化的快意、悲伤、疑虑、羞耻、松弛或伦理不适是什么。
- 本场需要：是继续积累，还是兑现一部分；是让人物获得喘息，还是让读者看见人物未见的代价。
- 情绪证据：由哪项选择、损失、生活细节或关系变化产生，不靠作者宣布“所有人都震撼”。
- 允许复调：同一结果可否同时带来释然与不安；若可以，不强迫所有人物同调。
- 禁止反向公式：不因刚写过低谷就机械安排胜利，也不因刚写过胜利就强行追加悲剧。

## 五、方案比较表：不计算“多样化总分”

下表只用于重大转折、高代价选择、核心反转或重复风险高的节点；普通场景不套用三行，不为凑数设置C案。

| 方案 | 如何解决当前问题 | 谁的什么选择推动 | 信息如何变化 | 即时情绪 | 后续收益 | 实际代价／受损者 | 与近章及已知作品的关系 | 暂不选的理由 |
|---|---|---|---|---|---|---|---|---|
| A |  |  |  |  |  |  |  |  |
| B |  |  |  |  |  |  |  |  |
| C（不采用已想到的熟套技法） |  |  |  |  |  |  |  |  |

比较时按以下次序判断，不给每项机械赋分：

1. 先排除人物、信息、因果和核心规则不成立的方案。
2. 再看哪个方案能完成本场状态变化，并保留必要的未决问题。
3. 再看情绪是否由此前积累而来，是否给读者可感知的事件结果。
4. 再看代价是否来自行动本身，而非作者为了续写临时惩罚人物。
5. 最后比较辨识度；若较常见方案最符合人物，可以采用，不必为奇而奇。
6. 选择记录须写明放弃项损失了什么，防止把所选方案说成毫无缺点的标准答案。

## 六、四书样本：同类问题为何有不同解法

以下均为限样本的I/T对照，不可拼成一套“经典标准流程”。

### 问题一：局部问题已经解决，下一段动力从哪里来

- **三国：**SG-01中，诛卓解决了具体掌权者问题，旧部处置、清算边界与城防却继续生成冲突；SG-02又以后方、粮食、名分和多中心行动改变战局。动力来自系统内尚未处理的资源与权限，不必立刻另造一个恶人。
- **水浒：**SH-01中，杀人、庇护、救援、入营等局部处理连续改变身份、地点和关系，下一问题从这次处理的新处境生长。重点是“后果转换”，不是“每次必更糟”。
- **西游：**XY-01中，招安、授事、处刑、守门、还阳许可分别只处理一层问题，残余成本、命令冲突、执行权限和未偿事项继续推进。须分清方案、许可与完成。
- **红楼：**HL-01中，赔礼、撤回、获助、到诊只结束部分场面，利益依赖、未说来意、家庭照护和疗效未知仍在运行。动力可留在低强度日常里，无须外部灾难升级。
- **决策提示（T）：**先判断旧方案究竟改变了哪一层状态，再从其残余影响选动力；四书样本不能证明某一种余波最适合所有故事。

### 问题二：不靠正面打斗，怎样形成可读的压力

- **三国：**SG-01的入宫、诱杀、书信与盟内资源冲突，以及SG-02的朝议、查验、秘密立状，使“知道正当目标却未必能执行”成为压力。
- **水浒：**SH-01以告发与宴饮并行、押解中的身体限制、酒店碎片情报和空间条件，让日常动作持续改变安全边界。
- **西游：**XY-01以雨时雨量核验、对弈中的截止时限、双重命令和簿册执行分离知识、能力与权限，静态场景也能推进。
- **红楼：**HL-01以赠物次序、探病机锋、请医程序和未公开来意组织关系压力；一句照护或礼让也可能改变下一步行动。
- **决策提示（T）：**先选压力源是时间、资源、制度、关系还是信息，再选场景；不要见到“非打斗”就统一写唇枪舌剑或全员机锋。

### 问题三：怎样让群体不是主角能力的放大器

- **三国：**SG-01、SG-02的同盟包含功劳、粮食、土地、名位和退出成本，次要人物能泄露、接应、拒绝或改变战局。
- **水浒：**SH-01的帮助受报恩、家庭安全、职位与生活方式限制；视线通过教学、寻找、结义、护送交接，旧人物目标不因此消失。
- **西游：**XY-01的团队条件涉及生计、赦免、自由与承诺，组织决策经建议、批准和执行；个人战果与同盟、群体损失分账。
- **红楼：**HL-01同一家务或聚会容纳多种目标，仆役、请求者、执行者的有限裁量会反向改变主线。
- **决策提示（T）：**先让重要配角在主角不在场时也有一件要做的事，再检查其行动是否真实改变资源、信息或后果；不是给每人一段口号就算群像。

### 问题四：高潮之后要不要附加代价

- 三国样本提示核对系统后果，水浒样本提示保留身份与生活余波，西游样本提示个人与群体分账，红楼样本提示公开收束未必等于私下和解。
- 共同可用的决策不是“必须惨”，而是逐账问：谁受益、谁受损、什么已偿还、什么仅暂缓、什么仍无处置。
- 若行动本来就完整解决该层问题，可以真正收束；硬加灾祸同样会破坏因果与情绪信用。

## 七、常见桥段何时允许，何时必须重做

常见桥段不是禁用素材。关键是它是否由本作人物和既有条件生成，并在本次产生新结果。

| 常见桥段 | 可以保留的条件 | 必须重做的信号 |
|---|---|---|
| 开篇即处危机 | 危机是旧因果的即时结果，人物有具体处置，后文承担损失 | 只为抓手凭空遇袭，随后无代价重置 |
| 被轻视后证明能力 | 对方轻视有信息与利益依据，证明过程改变权限或关系，不靠全场围观惊叹 | 固定“轻视—挑衅—展示—震惊—后悔”，换职业仍不变 |
| 临场救援 | 救援者早有目标、位置和行程成本，被救者仍有选择与后果 | 救援者无铺垫到场，专为主角清除全部困难 |
| 误会转为冲突 | 双方信息来源、核验障碍和利益均成立，澄清也留下关系成本 | 一方拒绝显而易见核验，只为拖延而误会 |
| 谈判或宴饮藏多重目的 | 各方公开话语与私人目的不必全是假，场内有实际承诺或资源变化 | 所有人统一阴阳怪气，饭后只剩作者解释 |
| 计谋成功 | 利用既有信任、通道和时间差，保留反制与意外，采纳者承担责任 | 对手集体失智，计划依赖作者才知情的新规则 |
| 胜利后有余波 | 余波来自手段、身份、见证者或未处理者，且影响可追踪 | 每次胜利立刻更强敌人或更惨事故 |
| 章末留下问题 | 已兑现本场部分结果，未决项具体、有方向且后文登记兑现 | 只隐去姓名、话说半截或无故截断动作 |
| 主题或意象重复 | 本次增加新信息、新关系变化或新情绪，保留理由可说明 | 只重复物象、警句和感悟，人物与条件均未变化 |

“没用过的写法”也可能不合格；若它不符合人物目标与因果，不能凭陌生感保留。
“别人用过的写法”也不必自动删除；先核对具体场景组合、人物关系、事件序列和表达，再作人工判断。

## 八、重做与局部修改的分界

### 必须回到设计层重做

- 新剧情七问显示只是换名、换地图、换能力外观，冲突来源、关系结构与解决序列仍可逐项对应已有作品。
- 为预定胜负让关键人物放弃合理核验、泄露不可能知道的信息，或突然失去既有能力。
- 核心反转只靠临时新增规则、能力、物件或身份，删去补丁后因果即崩塌。
- 近章剧情指纹重复同一冲突来源、行动顺序和情绪兑现，本次没有新信息、新变化或新情绪。
- 配角、对立者仅充当送资源、受羞辱或解释主线的工具，无法说明其自身下一步。
- 方案不推动本书特有主线，只能证明“这一段很热闹”。

### 可以定点修改

- 人物行动、信息与结果均成立，仅有个别重复句式、过度总结、形容词堆叠或解释性对话。
- 某句对话声音与身份不合，但改变说话方式不会改变事件因果和其他人物选择。
- 一处细节功能不明，可通过删改细节本身解决，不需借它重写既定结果。
- 有意义的主题呼应已经成立，只需删去重复说理，让新信息或新情绪自行显现。

禁止用同义词替换、调乱句序或更换名词来“处理”上述设计层风险；那只会遮蔽来源，不会增加原创性。

## 九、原创微型情境一：停水夜里的抢修

> 仅作方案比较，不是正文，不含任何项目正式设定。

### 1. 问题与人物

- 剧情问题：老城区主管破裂，维修工程师唐荇须在清晨前恢复供水；全面关阀会中断一家社区诊所的清洗与设备冷却，分片施工又会延误道路复通。
- 唐荇：想修好管道并保住执业信誉，不愿再像上次那样隐瞒风险；她能调度两组工人，却无权命令诊所转移。
- 诊所负责人陆医生：要守住夜间患者安全，手头只有不完整的停水通知，能调整诊疗，却不能承担无条件停诊。
- 沿街冷库店主：担心备用水箱被征调后货物受损，掌握一处可接入的临时水源，但不愿无偿开放。
- 读者信息：知道唐荇上次隐瞒造成过不信任；诊所和店主最初不知道这件事，不能据此立即怀疑她。

### 2. 情绪任务

入场是紧迫感与不信任残留，目标不是“专家打脸众人”，而是让各方在信息逐渐可核对后作出有成本的合作。
释放只能来自供水方案真正执行和患者安排落地，不能来自唐荇一段技术演说。

### 3. 三案比较

| 方案 | 行动与信息 | 情绪兑现 | 后续影响与代价 | 判断 |
|---|---|---|---|---|
| A 公开检测后按常规应急分工分流 | 唐荇公开完整检测；陆医生据最低水量自行暂停非必要项目；店主按明码价格出售临时水，维修组先保诊所再修路 | 公开数据转化为可执行安排，释放来自患者与供水都得到具体处置 | 道路复通延后，维修预算增加，诊所损失部分业务 | **选择**；常见方案最符合清晨时限，且三方均保留决定权 |
| B 三方以可核验时间表交换资源 | 唐荇公开完整风险；陆医生给出最低用水时段；店主提供水源，维修组以人工搬运和后续清理作交换 | 从互相防备转为有限信任，患者安排逐项落实才释放 | 人工搬运占用抢修工时，道路复通进一步延后；唐荇承担工期责任 | 可行但不首选；工期可延且预算不足时可改选 |
| C 放弃当夜全面修复，先转移诊所并保留破管隔离 | 唐荇承认能力边界，陆医生自主组织转移，店主只提供短时储水 | 不是胜利，而是及时止损后的疲惫松弛 | 维修目标延期，居民不满；唐荇信誉受损但未再隐瞒 | 资源不足时的有效备选，不写成失败惩罚 |

A采用较常见的“公开数据＋标准应急分工”，但不靠独断、强制或人物降智；它最符合清晨时限，所以选择A。
B明确不采用“公开对质后众人服从”的熟套解法，但更新颖并不等于更合适；若预算不足且工期可延，B可成为优选。
若水源和施工能力都不足，则改选C，不能临时让水源扩容或让诊所放弃自主权。

## 十、原创微型情境二：结业照相馆的告别展

> 仅作低强度、非危机型方案比较，不是正文。

### 1. 问题与人物

- 剧情问题：县城照相馆结业前两小时，学徒许葭发现师父把部分顾客明确淘汰的肖像底片做成公开告别展；场地当晚须交还，撤展会中断师父筹划多年的告别。
- 师父：想证明这些照片保存过普通人的生活，不愿承认“被拍摄者不要”也是档案历史的一部分。
- 许葭：想保住师徒关系与照相馆名誉，也知道原始登记册上只有部分照片具有公开展示授权，另一部分没有许可记录。
- 老顾客周女士：来取亡妹照片，尚未知道照片已入展；她有权决定撤下，却不负责替师父成全仪式。
- 读者信息：先从登记册知道授权缺口，师父不知道许葭已发现；周女士到场后才获得选择信息。

### 2. 情绪任务

从怀旧与结业不舍，转为对“保存是否等于有权展示”的不适，再寻找不抹除任何人的有限收束。
不让周女士用一番大道理教育所有人，也不以师父年老为由取消其责任。

### 3. 三案比较

| 方案 | 行动与信息 | 情绪兑现 | 后续影响与代价 | 判断 |
|---|---|---|---|---|
| A 先撤未授权照片，保留已授权部分 | 许葭出示登记册，师父亲手撤下无许可照片；周女士到场后可自主决定自己那张 | 仪式被削减但不必全部取消，缺憾直接可见 | 展览大量留白，师父须接受多年筹划不完整；其余顾客仍须后续确认 | **选择**；登记册能够区分授权范围且只剩两小时，先执行边界明确的常规止损 |
| B 周女士只处理自己的照片，师父公开核查其余授权 | 周女士自主选择撤下或许可，不承担全场裁决；师父向到场者说明登记缺口并暂停其余争议照片 | 一个人的选择促成公开规则变化，不必靠羞辱认错 | 仪式气氛受损，其他顾客稍后仍需逐一答复 | 可行但不首选；须以周女士自愿发言为前提 |
| C 当场闭馆，改为归还与自愿留存 | 许葭先向师父出示登记册，再告知周女士；公开仪式取消，当晚交场前来人可取回、留档或签后续展示许可，三种选择并存 | 怀旧没有圆满复原，但师父亲手撤下第一张未授权照片，关系出现具体变化 | 师父失去筹划多年的仪式，须联系其他顾客；许葭承担当场清场和后续联络工作 | 条件性备选；仅当比较前已确认授权缺口占多数、核心展区无法保留或两小时内无法分区撤下时采用 |

当前题设选择A，不以“闭馆归还更彻底”预设它优于可执行的部分展览。C不采用“隐藏真相保住仪式”或“公开揭露完成惩戒”的熟套解法，重点放在归还、拒绝、许可三种实际结果；A、B、C均不是违规稻草人，选择只能使用比较前已明确的授权范围、数量、时间和资源条件。
师父不必当场完全想通；他是否愿意继续联系顾客，才是后续可检验的关系变化。

## 十一、反模板与原创性审查记录

### 1. 分级保存的记录

专项审查须保存以下字段；普通场景可将它们并入最小核心记录，不重复建账。最小核心记录只写当前问题、行动者目标与信息、实际行动与结果、代价及未决项；重大转折、高代价选择、核心反转或高重复风险节点再启用完整三案和专项审查。

- 审查对象、版本、日期、审查人及是否独立于创作者。
- 对比范围：当前方案、近期正文、最近20章剧情指纹、人物与规则档案、实际读过的参考文本、工具及参数。
- 具体位置：相似点、差异点、证据来源、新信息／新变化／新情绪、风险等级和处理建议。
- 无法覆盖的对比范围必须明示；不得写“绝无相似”或“绝对原创”。
- 自动结果只作定位线索，最终记录人工文学判断、修改稿与复验结论。
- 人物行动卡、情绪设计卡、五本长期故事账已有相同字段时直接引用；逐场只更新受影响项，阶段／卷级再共同核对。

### 2. 七问复核表

| 七问 | 本情境的证据问法 | 不合格处理 |
|---|---|---|
| 是否只是常见套路换名 | 去掉职业、时代和名词后，关系与事件序列是否仍逐项重合 | 回到冲突来源和人物目的重做 |
| 是否与最近章节重复 | 对照近20章的冲突、信息、选择、结果和结尾，不只对照题材 | 无增量则合并、删除或重新设计 |
| 是否与已有作品具体剧情高度相似 | 记录实际可比文本、场景组合和差异，不凭模糊印象裁决 | 高风险组合整体重构，不换词遮掩 |
| 是否有本书人物自然产生的独特行为 | 行为能否追溯到此人经历、利益、底线和当下信息 | 补自主行动模拟；补不出则换方案 |
| 冲突来源是否具体 | 障碍是否来自本作资源、关系、规则，而非通用恶人挑衅 | 重找冲突双方的真实不兼容处 |
| 解决方式是否体现人物、规则与前期因果 | 结果是否由此前条件与当场选择共同完成 | 删除临时能力或侥幸，重建解决链 |
| 是否推动本书特有主线 | 本场后出现了哪些只有本作才能继续的后果 | 无主线价值则删并或重设状态变化 |

### 3. 本稿两个情境的示范审查

| 位置 | 相似／套路风险 | 差异与新价值 | 风险 | 处理建议与人工结论 |
|---|---|---|---|---|
| 情境一A案 | 公开技术方案易形成专家压服 | 检测公开、诊所自主缩减、店主自愿出售，权限链完整；常规方案可因时限而最适合 | 中低 | 选择A并保留预算、道路与业务代价；不把“常见”本身当错误 |
| 情境一B案 | 多方合作可能写成人人通情达理 | 店主索取劳务、诊所只给最低时段、工程师承担延期，目标仍不完全一致 | 中 | 不首选是因为工时条件，不是因为合作较新颖；条件改变可改选 |
| 情境一C案 | 放弃目标可能被误当反高潮 | 在资源不足时保护患者并兑现不隐瞒，仍有实质状态变化 | 中低 | 仅作条件性备选，不把“承认失败”升格为更高级固定答案 |
| 情境二A案 | 只撤未授权照片可能变成技术修补 | 师父实际撤片、周女士保留决定权，方案在权限上成立 | 中 | 当前登记册可辨认且时间紧，选择A并保留其余待确认项；若比较前确认缺口占多数或无法分区撤下，再改选C |
| 情境二B案 | 公开说明可能变成惩戒仪式 | 周女士只决定自己的照片且自愿发言，师父核查其余授权，不由一人裁决全场 | 中 | 以自愿和后续核查为条件，不追求公开羞辱 |
| 情境二C案 | 自愿选择可能变成程序说明 | 新情绪来自师父亲手撤片和取消仪式，代价落在人物行动上 | 中 | 正文训练时减少授权解释，保留三类顾客选择的不同结果 |

本稿对比范围仅为五份阶段研究、项目规则及本稿新建情境，未检索也不掌握全部既有小说、影视和真实案例。
因此上述“高／中／中低”是当前方案风险，不是抄袭鉴定；对两个情境的外部相似性无法穷尽对比。
后续若发现可识别同类作品，应登记具体文本、场景组合、相似与差异，再决定是否整体重构。

### 4. 对话与句式审查

- 逐人抽读对话，遮去姓名后检查其用词、回避方式、说到何种程度是否仍可由身份和处境区分。
- 不用“一个冷静、一个暴躁、一个幽默”的固定声纹代替人物；同一人面对上级、亲属、陌生人可有不同表达。
- 标出连续机械转折、重复解释、同构情绪句和事后哲理总结，结合前后文判断是否真有重复。
- “他微微一笑”“就在这时”“不是……而是……”等不作全局禁词；只在无功能、重复或不合场景时定点处理。
- 有意义的重复须写清新增内容；没有新增信息、变化或情绪时，不以“风格”作为保留理由。

## 十二、训练验证与版本更新

### 1. 最小验证闭环

1. 题目只规定创作问题与必要约束，不预写必须采用的经典技法。
2. 保存最小核心记录；重大转折、高代价选择、核心反转或高重复风险题目另存至少三案比较及选择理由，避免只留最后正文而无法检查决策。
3. 保存未经修饰的训练原稿；训练稿与正式正文永久分离。
4. 由未参与该次创作的独立审稿者按文本定位问题，不向审稿者暗示必须认可设计意图。
5. 设计层问题退回重做，语言层问题定点修改；保留失败原因，不只保存成功稿。
6. 对修改稿实际复验，确认旧问题消除且未引入人物、信息或因果新问题。
7. 单次合格只记“该题该稿复验结果”，不得升级为稳定规则；AI模拟读者必须明确标注，不能冒充真实反馈。

### 2. 本稿建议的后续训练题，不代表已执行

- 将情境一分别按B、C写成短训练稿，比较“完成目标”与“及时止损”是否都能产生可信情绪，不预设B必胜。
- 将情境二写出三种顾客选择的后果，检查是否又把所有选择导向同一种师徒和解。
- 另拟一个无外部反派的日常问题，检验决策树能否在信息差很少时仍产生人物驱动。
- 用同一人物连续完成两个不同问题，检查其目的和说话方式是否连续，而非每题重建一个方便的人格。

### 3. 规则更新触发条件

- 新阶段研究出现反例或新的解决机制时，标明新增证据范围，修订对应条目，不覆盖历史版本。
- 训练反复暴露同一决策缺口时，先记录失败样本，再讨论是否修改规则；不得凭一次好稿增加“必用”条款。
- 正式全书交叉研究、PHASE 5训练及真实读者资料尚未完成本稿所需验证，后续不得倒填为已完成。
